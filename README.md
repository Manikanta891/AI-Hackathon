# AI-Hackathon

A modern ChatGPT-inspired frontend application built during the TCS AI Hackathon. This project focuses on delivering a smooth conversational experience with chat history management, media support, and a dynamic user-friendly interface.

## Features

* ChatGPT-like responsive UI
* Stores chat history using Local Storage
* Dynamic greetings like Good Morning, Good Afternoon, and Good Evening based on current time
* Media upload support
* Clean and interactive chat experience
* Fast and lightweight frontend design

## Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Local Storage API

## Use Case

This project was developed as part of the TCS AI Hackathon to create an AI-style conversational frontend interface with a focus on user experience and local data persistence.

## Future Improvements

* AI API integration
* Authentication system
* Cloud-based chat storage
* Voice input support
* Theme customization
